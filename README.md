# godot-ai-games
Desenvolvimento de jogos 2D com Godot 4 e Claude Code, feito inteiramente pelo navegador.

- Motor: Godot 4.7.2 (GDScript, renderizador Compatibility, exportação Web)
- Instruções para o Claude: [CLAUDE.md](CLAUDE.md)

## Comandos principais
```bash
tools/install_godot.sh --templates   # instala Godot + modelos Web
tools/run_tests.sh                   # testes automatizados
tools/export_web.sh                  # gera o jogo Web em build/web/
tools/web_smoke_test.sh              # abre o jogo num navegador sem tela e tira uma foto
```
